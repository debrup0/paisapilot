# PaisaPilot 💸

### Your Personal Finance Co-Pilot

PaisaPilot is a modern, interactive personal finance application designed for Gen Z. It helps users manage a limited ₹10,000 budget over 30 days, make informed spending decisions, and understand the impact of their financial choices.

## ✨ Features

- **Budget Tracking:** Monitor your budget, expenses, and remaining balance.
- **Daily Allowance:** Understand how much you can spend each day.
- **Savings Goals:** Track progress toward your financial goals.
- **Spending Insights:** Understand spending patterns and financial commitments.
- **Financial Decision Simulation:** Explore how potential purchases may affect your budget.
- **Financial Health:** Review your projected balance, financial risk, and overall financial position.
- **Interactive Dashboard:** Access key financial information in one place.

## 🎯 Purpose

PaisaPilot goes beyond basic expense tracking by connecting spending, savings, commitments, and financial planning. Its goal is to help users make smarter financial decisions before spending.

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder in a terminal.
3. Install dependencies using `npm install`.
4. Start the development server using `npm run dev`.
5. Open the local URL shown in the terminal.
